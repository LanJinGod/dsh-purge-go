# dsh-purge-go v0.2.2

首个公开版本（AGPL-3.0）。

把桌面版 dsh-purge 的「提示词注入」内核抽成独立 DSH 插件，按 dsh-go 的原生插件协议重写：只依赖官方扩展点，零运行时依赖，同一份代码跑在手机本机引擎（Android + PRoot）、SSH 主机和桌面版 DSH 上。

## 亮点

- **正文注入**：新增提示词段 `dsh-purge`（order `-100000`），正文来自 `<DSH_HOME>/prompt-inject.md`，缺失时用包内 25 KB 默认正文；`system-prompt/assemble` waterfall 把它顶到最前，并压掉 `harness:identity` / `deployment:persona-prefix` / `deployment:persona-suffix`。
- **能力协议段**：`dshpg-capabilities`（order `-99999`），可用 `<DSH_HOME>/dsh-purge/capabilities.md` 覆盖。
- **目标卡**：`dshpg-objective`（order `-99998`），从 `redteam/current` 读取当前靶标，写成「只打 X / 范围 / 不打其它单位」的一段提示；没有靶标时返回空串。
- **地区门**：`agent/pre-step` 判定任务文本里的目标，命中禁止范围就写禁止句并收掉这一轮；字面 IP 走随包网段表（v4 6354 段 / v6 2792 段），纯离线。
- **拒答续跑**：`agent/status` 在一轮以逃避句收工、用户没接话时追一句把任务拉回来；账本按 seq 去重，每会话上限 2、冷却 60 s。
- **红队资产**：23 条技能与预设随包同步到 `<DSH_HOME>/redteam/`、`<DSH_HOME>/.agent-presets/redteam/`。
- **题材分类扩展层**：`/purge cat *` 增删题材分类，组装时拼进正文的标记区，幂等且不覆盖手改正文。
- **手机端界面**：dsh-go 状态条、2 个面板、1 个加号工具、5 张只读工具卡（≤8 KiB）；没有桥接的宿主自动退化为纯命令 + 工具。

## 安装

三种方式，任选其一。

```bash
# 1) 自解压安装器（Android / PRoot / 任意 Linux，自动登记 profile + 建软链）
bash dsh-purge-go-0.2.2-selfinstall.sh
bash dsh-purge-go-0.2.2-selfinstall.sh --check      # 只体检
bash dsh-purge-go-0.2.2-selfinstall.sh --uninstall  # 卸载

# 2) DSH 插件命令（桌面版 / 任意宿主）
dsh plugin --profile web add /绝对路径/dsh-purge-go

# 3) 从 tgz 解包后按 2) 安装
tar -xzf dsh-purge-go-0.2.2.tgz && dsh plugin --profile web add "$PWD/package"
```

装完**完整重启引擎**（技能与预设在插件加载时同步）。

## 运行环境

- Node.js ≥ 22.19；DSH 引擎 `>=0.2.1-rc.2 <0.3.0-0`（ESM，Cordis 插件体系）。
- 零运行时依赖，不需要 `npm install`。
- 已实测：Android 15（内核 6.6.118，aarch64）+ Debian 13 PRoot 容器 + DSH 0.2.2-rc.1：56 例单元测试全通过，真引擎烟测段顺序 `dsh-purge > dshpg-capabilities > dshpg-objective > agent:instructions`，首段正文 26794 字节，5 个工具 schema 全部通过，工具卡 390 字节。
- 设备与宿主支持矩阵见 [README](README.md#支持设备与宿主矩阵) 与 [docs/COMPATIBILITY.md](docs/COMPATIBILITY.md)。

## 已知限制

- 工具卡只读（dsh-go 第 0 期不支持卡上点按），改状态请用面板或 `/purge` 命令。
- 与桌面版 dsh-purge 同装会撞 `/purge` 与 5 个工具名：只警告不报错，但状态文件会互相覆盖，建议一个宿主只装一个。
- 不含桌面版的红队评分、`/rules`、`/skills`、`/rewind` 与自动更新。
